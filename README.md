# AI-Driven Resume Screening using UiPath Agentic Automation

## 📌 Project Overview

AI-Driven Resume Screening is an intelligent recruitment automation solution built using **UiPath Agentic Automation**. The solution automates the end-to-end resume screening process by extracting candidate information, classifying resumes, evaluating candidates against predefined job requirements, and recommending whether to shortlist or reject each candidate.

This solution helps organizations reduce manual effort, improve hiring accuracy, and accelerate the recruitment process.

---

## 🚀 Features

- Monitor Outlook mailbox for incoming resumes
- Automatically download resume attachments
- Extract candidate information using UiPath Document Understanding
- AI-powered Resume Classification Agent
- Deterministic Evaluation Agent for profile assessment
- Generate Profile Matching Score
- Recommend Shortlist or Reject
- Store processed candidate data
- Send evaluation results to recruiters
- Configurable job requirements using Excel

---

## 🏗️ Solution Workflow

1. Monitor Outlook mailbox for new resumes.
2. Validate email subject to identify the job role.
3. Read hiring requirements from an Excel configuration file.
4. Download the resume attachment.
5. Extract candidate details using UiPath Document Understanding.
6. Classify the resume using the AI Resume Classification Agent.
7. Evaluate the candidate using the Deterministic Evaluation Agent.
8. Generate a Profile Matching Score.
9. Recommend Shortlist or Reject.
10. Update recruitment records and notify stakeholders.
